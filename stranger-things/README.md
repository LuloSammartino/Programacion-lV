# Stranger Things — Archivo Hawkins

Abrir `dist/index.html` en el navegador. No necesita instalación ni compilación.

- HTML y CSS solamente. Cinco páginas con un h1 por documento.
- La historia incluye un submenú con tres enlaces, operable con clic, teclado y pantalla táctil.
- Galería: seis fotos, ampliación, anterior, siguiente y cierre mediante enlaces y CSS :target.
- Contacto: validación HTML nativa. Es una demostración; no envía ni almacena mensajes. Los campos omiten name para no incluir datos personales en la URL. Para habilitar envíos, configurar un servicio receptor y agregar los atributos name.
- Diseño adaptable y estilos de foco para navegación por teclado.

Las imágenes promocionales provienen de Netflix Tudum: https://www.netflix.com/tudum/articles/stranger-things-season-5-trailer
